Count_Frequencies(l_words, l_categories, l_keywords)

d_frequencies = {}
for i in range(len(l_categories)):
    d_frequencies[l_categories[i]] = {}
    for keyword in l_keywords[i]:
        d_frequencies[l_categories[i]][keyword] = 0
for word in l_words:
    for i in range(len(l_categories)):
        if word in l_keywords[i]:
            d_frequencies[l_categories[i]][word] += 1
return d_frequencies

1. Every keyword of every category starts at 0 (“0 if it does not appear”, and no KeyError).

2. One pass over the words: in on the set says if the word is a keyword.

Whole words only: teams is not team.

Member B. Two steps. First we build the nested dictionary with every counter at zero; this gives the zeros the statement asks for, and it means the plus equals one never touches a key that does not exist. Second, one pass over the words of the document: for each word and each category, if the word is in that category’s set we add one. We loop by index because the two lists are parallel: category i goes with keyword set i. In the statement’s example, nasa appears twice, planet once and team once; teams is not counted because the comparison is between whole words.
