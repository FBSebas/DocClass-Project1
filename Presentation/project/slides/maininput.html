Member B. The main follows the statement’s steps. After the welcome, the keywords file is asked until it is valid. There are two ways to be invalid: the file does not exist, which arrives as FileNotFoundError from our reading function, or it has no data, which arrives as an empty list. One while covers both, because its condition is simply that we have no categories yet. The folder is asked the same way; our helper Folder_Has_Txt checks that it is a folder and searches for a txt file inside, stopping at the first one it finds.
