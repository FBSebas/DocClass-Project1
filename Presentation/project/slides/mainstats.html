# l_names: keywords in alphabetical order
# l_counts: their totals (parallel list)
k = 0
while k < 10 and len(l_names) > 0:
    pos = 0
    for i in range(1, len(l_counts)):
        if l_counts[i] > l_counts[pos]:
            pos = i
    stats.write(l_names[pos] + ": " +
                str(l_counts[pos]) + "\n")
    del l_names[pos]
    del l_counts[pos]
    k += 1

While classifying we also counted the documents of each category and the total occurrences of each keyword in the whole folder; a keyword that belongs to two categories is counted once per document, because it is the same word. The statistics file writes the percentage of documents of each category with two decimals, in the order of the keywords file and then UNKNOWN. For the top 10 we put the keywords in alphabetical order with their totals in a parallel list, and ten times we find the position of the maximum with the running-maximum pattern, write it, and delete it from both lists so the next turn finds the next one.
