def Read_Categories_Keywords(filename):
    l_categories = []
    l_keywords = []
    text = Read_Text_File(filename)
    for line in text.split("\n"):
        if ":" in line:
            parts = line.split(":")
            l_name = parts[0].split()
            if len(l_name) > 0:
                l_categories.append(l_name[0].lower())
                l_keywords.append(
                    set(parts[1].lower().split()))
    return l_categories, l_keywords

One line, step by step

"space: planet orbit nasa  "

split(":") → ['space', ' planet orbit nasa  ']

parts[0].split() → ['space']

parts[1].split() → ['planet', 'orbit', 'nasa']

split() with no argument cuts at 1 or more spaces and ignores the ones at the end.

Member A. We read the whole file and cut it into lines. A line with a colon has the category on the left and the keywords on the right. split without arguments solves the two difficulties the statement mentions: keywords separated by one or more spaces, and lines that end with spaces. The category and its set are appended at the same time, so both lists stay parallel. Everything is lowered because the documents are compared in lowercase. Empty lines have no colon and are skipped.
