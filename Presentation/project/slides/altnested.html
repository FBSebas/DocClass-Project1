d_frequencies as a nested list

def Count_Frequencies_List(l_words, l_kw_lists):
    l_freq = []
    for i in range(len(l_kw_lists)):
        l_freq.append([0] * len(l_kw_lists[i]))
    for word in l_words:
        for i in range(len(l_kw_lists)):
            for j in range(len(l_kw_lists[i])):
                if l_kw_lists[i][j] == word:
                    l_freq[i][j] += 1
    return l_freq

Member A. This is the statement’s own example of an alternative: a nested list instead of a dictionary. Each category is a row and each keyword a column, so l_freq[i][j] is how many times keyword j of category i appears. We wrote it and checked it against our dictionary version on news_01: the music row is 1 for singer and 2 for song, the same counts. The advantage is that it uses only lists. The disadvantages are that we need a third loop to find the keyword, where the set answered directly, and that the numbers are meaningless unless you keep the list of keywords next to them, while the dictionary carries the keyword name with its count.
