Member A. These are the types the statement imposes. The keywords of each category are a set because the only thing we ask is whether a word is a keyword, and in on a set answers that directly; also a set never stores a keyword twice. d_frequencies is a dictionary of dictionaries: first the category, then the keyword, then its number of occurrences. d_votes stores a tuple of two integers per category: occurrences and rounded percentage.
