def Document_Reader(filename):
    text = Read_Text_File(filename)
    clean = ""
    for c in text:
        if c.isalnum():
            clean = clean + c.lower()
        else:
            clean = clean + " "
    l_words = clean.split()
    return l_words

Letters and digits are kept (lowercase); any other character becomes a space.

NASA-team couldn't
→ "nasa team couldn t"
→ ['nasa', 'team', 'couldn', 't']

Member B. A word is a sequence of letters or digits; everything else separates. We go through the text character by character: letters and digits go into a new string in lowercase, any other character becomes a space. Then split cuts at the spaces, and several separators in a row do not create empty words.
