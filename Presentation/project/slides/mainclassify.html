Member A. For each name in the folder we build its path with os.path.join, which the statement makes mandatory, because it uses the right separator on Windows and on Mac. We sort the names so the output always comes in the same order. A txt file goes through Exercises 3, 4 and 5 inside a try, and the line is built by our helper Line_Of_Document: the file name, its category, the percentage of every category, and, unless it is UNKNOWN, the occurrences of each keyword of the winning category in alphabetical order. A file that is not txt gets the Attention message, written exactly as in the statement. The example at the bottom is the real line for news_01, identical to the statement’s example.
